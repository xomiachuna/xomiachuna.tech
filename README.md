# xomiachuna.tech
This is the source code behind [xomiachuna.tech](https://xomiachuna.tech).

## Building
Use `make dev` for local `hugo` dev server. Build with `make build`

## Deployment
1. Build locally with `make` - this will produce the static files (`public/`)
2. Commit changes (including `public/`) - the CI will deploy it.
